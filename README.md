# Mega Motors - Mobilidade Elétrica (prévia)

Site de demonstração em HTML, CSS e JavaScript simples, sem bibliotecas.

- Edite textos, produtos, preços e perguntas em `dados.js`.
- Fotos na pasta `imagens/`, vídeos na pasta `videos/` (veja o `LEIA-ME.txt` de cada uma).
- Abra `index.html` no navegador para ver.
